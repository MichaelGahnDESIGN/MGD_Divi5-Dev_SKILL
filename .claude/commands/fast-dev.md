# /fast-dev

Nutze den installierten Skill `fast-dev`. Seine mitgelieferte Quelle liegt in
`fast-dev/SKILL.md` dieses Repositories. Löse den Pfad relativ zur tatsächlichen
Skill-Installation auf; das aktuelle Arbeitsprojekt muss dieses Repository nicht enthalten.

Setze den freigegebenen Auftrag mit kurzem Playbook, vorhandenen Komponenten und
gezielten Prüfungen um. Halte Rückfallweg und Zugriffsschutz ein und arbeite bis
zum beauftragten Ergebnis weiter. Bei einem Release-Auftrag gehören Version, Tag,
GitHub-Release und das geprüfte Paket dazu. Ein Deployment braucht den dafür
freigegebenen Projektweg. Keine pauschale Freigabe für Zahlungen oder Löschungen.

In Codex den installierten Skill mit `$fast-dev` aufrufen; diese Datei ist eine
Befehlsvorlage für Umgebungen mit Unterstützung eigener Commands.
